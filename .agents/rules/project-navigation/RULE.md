# Maintain project navigation

Use `.agents/INDEX.md` to find where to read or edit when the location isn't obvious. Keep it to key entry points, not every file. Update it in the same change that adds, moves, or removes one. Maintain `.agents/RULES.md` when rules change.

Keep every `AGENTS.md` at or under 100 lines. Put directory-specific guidance in that directory's own `AGENTS.md` and link to authoritative files instead of duplicating instructions.
